# Images Directory

Place your images here:
- Profile images
- Project screenshots
- Hero/banner images
- Any other images for your portfolio

## Recommended Image Sizes

- **Profile Image**: 250x250px or larger (square)
- **Project Images**: 800x600px or similar 4:3 ratio
- **Hero Images**: 1920x1080px or similar 16:9 ratio

## Supported Formats

- JPG/JPEG
- PNG
- GIF
- WebP

## Reference in config.json

Use the path format: `/static/Content/Images/your-image.jpg`
